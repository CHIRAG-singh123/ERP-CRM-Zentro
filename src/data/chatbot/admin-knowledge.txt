Q: How do I manage employees?
A: As an admin, you can manage employees by navigating to Admin > Employees. Here you can view all employees, add new ones, edit their details, assign roles, track performance, view their activity, and manage permissions. You have full access to employee management features including performance metrics and audit logs.

Q: How do I add a new employee?
add employee
create employee
new employee
hire employee
A: To add a new employee, go to Admin > Employees and click the "Add Employee" button. Fill in their name, email, role, department, and other required information. The system will automatically send them an invitation email with default credentials (default password: Employee@123) to set up their account. You can also assign them to specific teams or departments during creation.

Q: How do I view employee performance?
employee performance
performance metrics
track performance
employee analytics
A: Navigate to Admin > Performance or Admin > Employees > Performance to see detailed performance metrics for all employees. You can view individual employee performance by clicking on their name, which shows their sales data, task completion rates, lead conversion metrics, deal values, and other key performance indicators. You can also export performance reports for analysis.

Q: How do I manage products?
manage products
product management
product catalog
A: Go to Admin > Products to manage your complete product catalog. You can create, edit, delete products, set prices, add categories, upload multiple images, manage inventory levels, set SKU numbers, add product descriptions, and control product visibility. You have full administrative control over all product information and can bulk update products.

Q: How do I view audit logs?
audit logs
audit trail
system logs
activity logs
security logs
A: Access comprehensive audit logs from Admin > Audit Trail. This shows all system activities including user actions, data changes, login attempts, permission changes, file uploads/downloads, and other important security events. You can filter by date range, user, action type, and export logs for compliance tracking and security analysis.

Q: What permissions do I have as admin?
admin permissions
admin access
admin rights
admin capabilities
A: As an admin, you have full system access including: managing all users and employees, viewing and editing all products, accessing complete audit logs, managing system settings and configurations, viewing all reports and analytics, configuring roles and permissions, managing companies and contacts, viewing all leads and deals, managing documents and files, accessing all chat conversations, and controlling system-wide settings.

Q: How do I change user roles?
change role
assign role
update role
modify user role
user permissions
A: Go to Settings > Users or Admin > Employees, find the user you want to modify, click Edit, and change their role. Available roles include admin (full access), employee (product and contact management), and customer (product viewing only). You can also assign custom permissions and team memberships. Changes take effect immediately and are logged in the audit trail.

Q: How do I export data?
export data
download data
export reports
export csv
data export
A: Most list pages have an Export button that allows you to download data in CSV format. You can export employee lists, product catalogs, contact lists, lead data, deal information, audit logs, and other system data for reporting, backup, or analysis purposes. Exports include all visible columns and can be filtered before exporting.

Q: How do I view system reports?
system reports
analytics
dashboard reports
performance reports
A: Navigate to Reports or Dashboard in the main menu to access comprehensive analytics including sales reports, employee performance metrics, product analytics, lead conversion rates, deal pipeline analysis, revenue trends, and custom reports. You can filter by date range, user, department, and export the data in various formats.

Q: How do I manage system settings?
system settings
admin settings
configuration
system configuration
A: Access Settings from the main navigation. Here you can configure user roles and permissions, manage teams and departments, set system preferences, configure email templates, manage integrations, set up workflows, configure security settings, and adjust other administrative settings. Changes affect the entire system and are logged.

Q: How do I manage documents and files?
edit documents
admin edit documents
upload documents
download documents
document management
file management
manage files
A: Open Documents from the Workspace menu to see all files in the system. Use "Upload Document" to add new files, click a row to preview or edit metadata, and use the action menu to download, replace, or delete files. Admins can manage all documents, view document versions, set permissions, organize files by folders, and track document access history.

Q: How do I manage contacts and accounts?
contacts
admin contacts
manage contacts
account management
manage accounts
companies
organizations
A: Go to Contacts or Accounts in the Workspace. Use search and filters to find records, click "Add Contact" or "Add Company" to create new ones, and open a contact or account to edit details, assign to accounts, link to deals, or review activity history. Admins can see and edit every contact and account, assign ownership, and manage relationships between contacts and companies.

Q: How do I use the chat feature?
admin chat
chat feature
start chat
chatting
team chat
messaging
A: Select Chat from the Workspace sidebar to start messaging. Pick a teammate or search for a name, then send messages and files from the conversation panel. Use the channel list to switch threads and continue ongoing chats. Admins can view all chat conversations, moderate discussions, and access chat history for compliance purposes.

Q: How do I manage leads?
manage leads
lead pipeline
view leads
lead management
A: Navigate to Leads in the Workspace to access the lead pipeline. You can view leads in Kanban board format (New, Contacted, Qualified, Won), create new leads, assign leads to employees, update lead status by dragging cards, view lead details, add notes, and track lead conversion. Admins can see all leads across the organization.

Q: How do I manage deals?
manage deals
deals pipeline
opportunities
deal management
A: Go to Deals in the Workspace to manage sales opportunities. You can create deals from qualified leads, set deal values, track expected close dates, assign deal owners, move deals through pipeline stages, add notes and activities, and view deal analytics. Admins have visibility into all deals and can reassign ownership.

Q: How do I view the dashboard?
admin dashboard
dashboard
analytics dashboard
overview
A: Access the Dashboard from the main navigation to see comprehensive system overview including key metrics, sales performance, employee activity, recent leads and deals, system health, and quick access to important features. The dashboard provides real-time insights and customizable widgets for monitoring business performance.

Q: How do I manage tasks?
manage tasks
task management
assign tasks
view tasks
A: Navigate to Tasks in the Workspace to create, assign, and track tasks. You can create tasks for yourself or assign them to employees, set due dates and priorities, add descriptions and attachments, track completion status, and view task analytics. Admins can view all tasks across the organization and reassign them as needed.

Q: How do I search for information?
search
find
lookup
elastic search
A: Use the global search bar at the top of the interface to search across leads, contacts, companies, products, documents, and other system data. The search uses fuzzy matching and will show results as you type. You can filter results by type and access items directly from search results.

Q: How do I manage companies?
manage companies
companies
organizations
client companies
A: Go to Companies in the Workspace to view and manage all client organizations. You can create new companies, edit company details, link contacts to companies, view company activity history, assign account managers, and track company-related deals and interactions. Admins have full access to all company records.
